## [Unreleased]

### Добавлено

- `GET /healthz` — лёгкая проверка живости для Docker и оркестратора
  (MongoDB намеренно не пингуется).
- Подтверждённая ротация токена: `/newtoken` только предупреждает,
  смена — по `/newtoken confirm`.
- Привязка группы: `/bind ID` / `/bind off` в личке и `/groupid` в группе.
- Автоочистка журнала отправок через TTL-индекс MongoDB по
  `LOG_RETENTION_DAYS` (`<= 0` — хранить вечно).
- Повторы доставки в MAX при временных ошибках (429/5xx) и keep-alive
  HTTP-клиент для `/wh/` и `/bot`.
- Видимая причина последней неудачной отправки в MAX в админке
  (`last_send_error`, `last_send_error_at`).
- Регистрация команд бота в MAX через `PATCH /me/commands` при старте.
- Корректное завершение: дренаж очереди sender и ожидание in-flight
  запросов при остановке сервиса.

### Изменено

- Ежедневная статистика считается по каждому пользователю отдельно
  (раньше все видели общий счётчик по всем).
- Сессия админки — HttpOnly-кука с SHA-256 пароля вместо передачи самого
  пароля.
- `RATE_LIMIT` и `QUEUE_SIZE` защищены от нулевых и отрицательных значений
  (такие значения откатываются к дефолту).

### Исправлено

- Паника в sender при закрытии очереди.
- Остаток дневного лимита больше не уходит в минус.
