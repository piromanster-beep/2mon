# Настройка HTTPS для 2mon

Для работы вебхуков MAX требуется HTTPS на 443 порту.

## 1. Установка Nginx и Certbot

```bash
sudo apt install -y nginx certbot python3-certbot-nginx
```

## 2. Конфиг Nginx

Скопируйте конфиг из репозитория и замените домен:
```bash

sudo cp deploy/nginx-2mon.conf /etc/nginx/sites-available/2mon
sudo sed -i 's/server_name 2mon.ru/server_name ваш-домен.ru/' /etc/nginx/sites-available/2mon
sudo ln -s /etc/nginx/sites-available/2mon /etc/nginx/sites-enabled/
sudo nginx -t
sudo systemctl reload nginx
```

## 3. Получение SSL-сертификата
```bash

sudo certbot --nginx -d ваш-домен.ru
```
Следуйте инструкциям Certbot (введите email, согласитесь с условиями).

## 4. Проверка
```bash

curl -sI https://ваш-домен.ru | head -5
```
Должен вернуть HTTP/1.1 200 OK.

## 5. Вебхук MAX

Вебхук настраивается через API MAX. Замените `ТОКЕН_БОТА` на токен из панели MAX:

```bash
curl -X POST "https://platform-api.max.ru/subscriptions" \
  -H "Authorization: ТОКЕН_БОТА" \
  -H "Content-Type: application/json" \
  -d '{
  "url": "https://ваш-домен.ru/bot",
  "update_types": ["message_created", "bot_started"]
}'
```

## 6. Сертификаты Минцифры для MAX API

Для работы с `platform-api2.max.ru` в Docker-образ добавлены корневой и выпускающий сертификаты Минцифры (папка `certs/`).

Сертификаты периодически обновляются. Актуальные версии — на портале Госуслуг: https://www.gosuslugi.ru/crt

При обновлении: замените файлы в `certs/`, пересоберите образ `docker compose up -d --build`.


Команды бота регистрируются отдельным запросом `PATCH /me/commands`
(делается автоматически при старте сервиса).

## 7. Сертификат Минцифры для сайта


По умолчанию сайт использует сертификат Let's Encrypt. Если для вашей организации требуется российский сертификат (или Let's Encrypt блокируется в вашей инфраструктуре), можно перейти на сертификат от Национального удостоверяющего центра (НУЦ) Минцифры.

### Получение сертификата

Сертификаты НУЦ Минцифры выпускаются бесплатно для физических лиц, ИП и юридических лиц. Заявка подаётся через портал Госуслуг.

**Для подачи заявления потребуется:**

    Запрос на выпуск сертификата в формате p10 (для ГОСТ) или csr (для RSA), подписанный УКЭП.

    Для OV-сертификата (с подтверждением организации) — документы, подтверждающие права на домен.

Создать запрос можно в программе «КриптоАРМ» (требуется «КриптоПро CSP» для ГОСТ).

### Установка сертификата в Nginx

После получения сертификата укажите пути к нему в конфиге Nginx, заменив пути к сертификатам Let's Encrypt.

**Директивы, которые нужно поменять в конфиге:**

    ssl_certificate — путь к вашему сертификату

    ssl_certificate_key — путь к вашему приватному ключу

**Важно: сертификат Минцифры не встроен в большинство зарубежных браузеров (Chrome, Safari, Edge). Пользователи будут видеть предупреждение о небезопасном соединении, пока не установят корневой сертификат НУЦ Минцифры на своё устройство.
** 
### Что нужно на стороне Zabbix

Если ваш сайт защищён сертификатом Минцифры, сервер, где работает Zabbix, должен доверять этому сертификату. Иначе вебхуки не будут доходить.

Для Linux-сервера Zabbix:

    Скачайте корневой и выпускающий сертификаты с портала Госуслуг.

    Добавьте их в системное хранилище доверенных сертификатов.

Важно: сертификат нужно добавлять не в сам Zabbix как приложение, а в операционную систему сервера, где Zabbix запущен. Zabbix использует системное хранилище доверенных сертификатов.
